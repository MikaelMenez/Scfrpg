# Character Builder 
esse é um sistema focado na criação e manutenção de personagens de d&d(Dungeons & Dragons)

## Funções adversas e simples
no arquivo prelude.kt encontra-se algumas funções úteis, mas que não fazia sentido criar um arquivo inteiro só para elas, nela se encontra a função infixa de divisão, uma vez que no d&d toda divisão deve ser arredondada para baixo

## Dados 
a lógica dos dados d4,d6,d8,d10,d12, d20 e d100 encontra-se no arquivo dados.kt

## Atributos
os atributos são retratados como uma dataclass chamada de atributtes, instanciada no arquivo atributtes.kt. Nela podemos encontrar a redefinição do operador de soma e do operador de subtração.
